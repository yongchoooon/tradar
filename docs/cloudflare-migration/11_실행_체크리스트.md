# 11. 전체 실행 체크리스트

## 최종 완료 선언

다음을 모두 만족할 때 migration 완료로 선언한다.

```text
Frontend: Cloudflare Pages
Object storage: Cloudflare R2
Public API path: Cloudflare Access + Tunnel
Backend/DB/OpenSearch/worker: Desktop Docker
Worker connection: Local Docker WebSocket
AWS workload: 없음
AWS deployment credentials: 없음
Backups: 복구 가능한 상태
```
